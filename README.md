# BatteryScope Pro

Android スマートフォンのバッテリー状態を詳細に計測・分析する診断アプリです。

AccuBattery のように充電セッションからバッテリー容量・健康度を推定でき、端末が公開する実際のバッテリー情報も確認できます。

## リポジトリ

**GitHub**: [https://github.com/namaemiteiii-net/BatteryScopePro](https://github.com/namaemiteiii-net/BatteryScopePro)

オープンソースでの公開を予定しています。Issue / PR 歓迎です。

## 主な機能

1. **バッテリー情報のリアルタイム表示**  
   残量・温度・電圧・電流・充電状態など（取得可能な範囲）

2. **充電セッションによる最大容量・健康度の推定**  
   充電中の電流積算と残量増加から満充電相当容量を推定

3. **充放電サイクル数**  
   - OS が公開するサイクル数（API 34+ の一部端末）  
   - アプリが記録した累積等価サイクル数

4. **計測履歴・CSV エクスポート**  
   Room によるローカル保存、履歴削除、CSV 出力

## 要件

- Android 8.0 (API 26) 以降
- ネットワーク不要・ログイン不要・広告なし

## ビルド手順

1. Android Studio Hedgehog (2023.1.1) 以降を推奨
2. 本リポジトリをクローンまたは展開
3. Android Studio で `BatteryScopePro` フォルダを Open
4. Gradle Sync を実行
5. 実機またはエミュレータで Run

```bash
git clone https://github.com/namaemiteiii-net/BatteryScopePro.git
cd BatteryScopePro
# Android Studio で Open → Gradle Sync → Run
./gradlew assembleDebug
```

生成 APK: `app/build/outputs/apk/debug/app-debug.apk`

## テーマ

- **システム**（初期値）: OS のライト/ダーク設定に自動追従
- **ライト**: 常にライトモード（テキストは濃色、背景は明るい色）
- **ダーク**: 常にダークモード（テキストは淡色、背景は黒〜チャコール）

端末・設定画面から切り替えできます。UI の色はすべて `MaterialTheme.colorScheme` 経由で、モードに応じて自動で切り替わります。

## 計測方法（容量推定）

1. アプリを起動した状態で充電を開始する
2. 残量が十分に増えるまで充電する（目安: 15% 以上の増加）
3. 充電を終了（または満充電）するとセッションが記録される
4. 複数回の有効セッションから中央値ベースで容量を推定
5. 設定画面でメーカー公称容量（mAh）を入力すると健康度を表示

### 推定の注意

- 推定値であり、実測の満充電容量ではありません
- 「安定」は測定の再現性を示すものであり、正確性の保証ではありません
- 電流が取得できない端末では充電量積算ができず、容量推定ができない場合があります
- 端末自身の消費やセンサー誤差の影響を受けます

## 制限事項

- 電流・サイクル数・満充電容量などは端末・メーカー・OS により取得できない場合があります
- 取得できない値は「取得不可」「未対応」と表示し、架空の値は使いません
- root 権限や非公開 API には依存しません
- ネットワーク通信・広告・解析 SDK は使用していません
- バックグラウンドでの常時監視は行いません（充電中のみ必要に応じてフォアグラウンドサービス）

## アーキテクチャ

```
ui/          Compose 画面 + ViewModel
data/        Room・Repository・Model
domain/      BatteryMonitor, Estimators, Trackers
util/        CSV エクスポート
```

## テスト

```bash
./gradlew test
```

主な単体テスト:

- 40%→70% / 1500mAh → 5000mAh 推定
- 残量増加 0 でのゼロ除算防止
- 電流欠損時に架空値を生成しない
- 異常サンプル間隔の検出
- 複数セッションの中央値・外れ値処理
- 公称容量不明時は健康度を算出しない
- 等価サイクル計算

## プライバシー

すべての計測データは端末内にのみ保存されます。外部サーバーへの送信は一切行いません。
